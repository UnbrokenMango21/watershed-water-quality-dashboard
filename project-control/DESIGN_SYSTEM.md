# Multi-Surface Design System

| Role | iOS | Android | QC Console | Public Dashboard |
|---|---|---|---|---|
| Primary | Hemlock `#0D5C4B` | Hemlock `#0D5C4B` | deep teal/navy | Calcite GIS accent |
| Water | `#167A8B` | `#167A8B` | `#135467`–`#2B8AA6` | `#007AC2` / `#005A91` |
| Canvas | `#F3F1E9` | `#F3F1E9` | `#F2F5F8` | `#EDF1F4` / `#F6F8FA` |
| Type | SF Pro | Roboto/Material | system web | Calcite/system GIS |

Field apps prioritize scanability and offline confidence. QC prioritizes dense review/audit visibility. The public dashboard prioritizes cartographic hierarchy, source transparency and fail-closed empty states. Native conventions are preserved rather than forcing identical components.
