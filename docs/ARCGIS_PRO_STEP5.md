# Step 5 — ArcGIS Pro Geodatabase Prototype

**Status:** Active
**Target:** ArcGIS Pro 3.7.x

## Project setup

Create a Map project named `Central_PA_Watershed_Platform` and store it on the Windows local disk (not OneDrive/Google Drive/shared cloud folders). The project creates a default file geodatabase automatically. Rename/use the working geodatabase as `CentralPA_Watershed.gdb`.

## Prototype datasets

Create the following empty datasets first. Domains, relationship classes, and final key enforcement are Phase 6.

### 1. SamplingSites — Point feature class
Spatial reference: WGS 1984 (EPSG:4326)

Fields:
- `site_id` — Text(36), required, stable UUID generated by application/backend later
- `site_code` — Text(32), required, human-readable site identifier
- `site_name_internal` — Text(160), internal only
- `site_name_public` — Text(160), public-safe display name
- `landowner_name` — Text(160), backend/private only
- `landowner_notes` — Text(1000), backend/private only
- `watershed_name` — Text(120)
- `site_status` — Text(20)
- `latitude` — Double
- `longitude` — Double
- `access_notes_internal` — Text(1000), backend/private only
- `site_description` — Text(2000)
- `created_at` — Date
- `updated_at` — Date
- `schema_version` — Text(20)

## Phase 5 completion criteria

- ArcGIS Pro project is saved locally.
- `CentralPA_Watershed.gdb` exists and is the default geodatabase.
- Five empty prototype datasets exist with the field schemas above.
- `SamplingSites` and `SamplingEvents` are point feature classes in WGS 1984.
- No production/historical observations have been loaded yet.
- No landowner/private fields are intended for future public views.

Phase 6 will add domains, GlobalIDs/GUID foreign keys, relationship classes, editor tracking, attachments where appropriate, and final publication-ready schema enforcement.
