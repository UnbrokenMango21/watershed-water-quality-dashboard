# Publication Summary

The publication subsystem is implemented but deliberately gated.

The private approved-authoritative ArcGIS service is separate from the older QC/staging service. Four hosted public views expose only explicitly public fields and must remain anonymous, query-only and free of protected workflow/identity data.

No environmental conclusion is established by software tests. TEST-014 is controlled test data and is unsuitable for final scientific publication proof. The unresolved historical 117-record/5-site dataset also remains excluded.

Final proof requires a provenance-cleared non-test observation, authorized human review, item-scoped OAuth credentials, and readback through the authoritative service, public views and dashboard.
