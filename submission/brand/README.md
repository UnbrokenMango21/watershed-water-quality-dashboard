# PA Watershed Watch brand package

The `assets/` directory preserves the design package supplied on September 26, 2026. It is the editable source and store-export set for the release brand. The iOS asset catalog and Android launcher resources contain build copies of the corresponding files.

- `assets/logo/` — outlined vector mark and wordmarks with raster previews.
- `assets/ios/` — iOS light, dark, and tinted icon masters and 1024-pixel exports.
- `assets/android/` — Android adaptive foreground, background, and monochrome layers.
- `assets/play/` — Google Play icon and feature graphic.
- `assets/screenshots/templates/` — layout references marked **PENDING**. They are not app screenshots and must never be uploaded as screenshots.
- `assets/asset-manifest.csv` — export sizes and intended destinations.

The supplied ZIP contained assets only. The user subsequently supplied the standalone design page; its embedded package data was decoded into `copy/` and `privacy-review-worksheet.csv` without executing the page's scripts. The Apple description, promotional text, and keywords have been applied to the existing App Store Connect draft. The Play listing remains unverified.

The supplied TestFlight text in `apple-app-store-copy.txt` describes the earlier Build 13. `copy/testflight-build-14.txt` is the current testing text for the branded Build 14, pending upload and processing in App Store Connect.

Use actual current app captures for store screenshots; exclude personal accounts and controlled test observations. The privacy worksheet and support/reviewer copy contain unresolved owner placeholders and are **drafts**, not approved disclosures. App Store and Play privacy declarations, support details, and scientific claims still require evidence and owner review.
